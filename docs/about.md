# 怎样找到适合自己的项目

从你的兴趣和职业目标出发，先看培养内容，再比较申请要求与费用。

## 五个入口

1. **[院校导航](/schools.html)**：按学校浏览项目速览，了解同校不同学院、方向和学制。学校页面可按项目名称、院系或培养重点快速定位；项目末尾可返回导航。
2. **[项目检索与对比](/programs.html)**：按地区、大学、方向、学制和申请途径组合筛选，搜索“金融工程”“Python”“431”“GRE”等关键词，选取 2–4 个项目并排比较。
3. **[申请时间线](/timeline.html)**：按推免、统考或境外申请切换准备节奏，再按地区、学校或收藏学校查看原始日程。
4. **[学长学姐去向](/alumni.html)**：了解统计学院毕业生的升学选择、准备经历和职业方向。
5. **每校页面底部的官方链接与 PDF**：深入阅读招生简章、课程介绍和项目材料。

## 先想清楚三个问题

| 你关心什么 | 阅读时重点比较 |
|---|---|
| 希望学什么、做什么工作？ | 代表课程、理论与实践比例、编程要求、实习或毕业项目 |
| 能通过什么途径申请？ | 推免或统考、考试科目、先修课程、语言和 GRE/GMAT、工作经验 |
| 学习成本与时间是否合适？ | 学制、校区、学费币种及计费周期、生活预算、资助条件 |

## 怎样看年份

本站面向 **2028 年入学准备**，招生资料主要参考 **2026—2027 年入学批次**。每项日期、费用和录取数据应结合旁边注明的年份阅读；目标届别发布新通知后，以新通知为准。

往届截止日可以帮助安排准备节奏，不能直接顺延一年作为新的截止日。

## 比较时留意这些区别

- **学制筛选**：按资料中明确写出的年数或月数归类；多种学制、开放区间、按学期或学季计的项目分别列出。工作经验不算学制，未能核实的归入“待核验”。先修课减免、不同修读路径仍需查看项目说明。
- **申请途径筛选**：推免、统考和申请制可以并存，只依据所列参考资料；“含待核验途径”可以找出仍需确认的条目。选择推免或统考并不代表已确认 2028 年招生名额。
- **对比阅读**：“要点速览”展示原文节选，逐项点“展开全文和来源”查看完整限制条件与依据；“完整资料”一次展开所有项目。表格内可以横向、纵向滚动，项目名与比较维度固定显示。
- **项目与培养方向**：同一学位下可能有多个方向，共用的招生名额不能重复相加。
- **最低要求与录取结果**：达到官网最低要求，并不等于一定获得录取。
- **费用周期**：每年、每学期、每学分和全程费用需要分别比较。
- **毕业去向范围**：单个项目、学院和全校的就业数据含义不同；个人录取经历适合参考准备过程。
- **录取与入读**：一个人可能收到多个录取。“学长学姐去向”将最终选择与其他录取分开列示。

院校导航和项目检索的筛选条件保留在页面地址中，刷新后可恢复，也可以复制筛选链接。对比选择保存在当前浏览器中；复制对比链接后，同学可以直接打开相同的项目组合。

## 保存自己的项目清单

在项目检索或学校项目页点击“☆ 收藏”，再到[我的收藏](/programs.html?saved=1)继续筛选、比较。收藏数量不受一次最多 4 个对比项目的限制。“导出当前结果 CSV”会导出全部匹配条目，含原始参考年份和资料页链接。

收藏保存在当前浏览器和当前站点；Vercel 与 Cloudflare 地址的收藏分别保存，清除浏览器数据也会移除收藏。换设备或换站点前，点击“导出收藏备份”，在新位置“导入收藏备份”即可合并恢复，不覆盖已有收藏。

时间线可只看收藏项目所在学校。准备路径卡片属于规划建议；逐校日程保留报告对应年份，不自动推算 2028 截止日。复制该校时间线链接可直接分享当前学校与准备路径。
