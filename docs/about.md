# 关于这个知识库

本网站汇集金融数学专业班会调研材料，用于了解不同大学的硕士项目、课程、申请路径与准备节奏。

## 如何使用

1. 从 **院校导航**进入单校报告，查看八章完整内容和来源清单。
2. 在 **项目检索**中输入专业、课程、考试代码等关键词，按地区、大学与方向筛选。
3. 选取最多四个项目或培养方向，比较申请要求、课程、费用与适配性；可复制对比链接。
4. 到 **申请时间线**查阅总体准备节奏和单校实际日程。
5. 每份报告可下载原始 Markdown 与配套 PDF；跨校项目索引可下载为 CSV。

## 年份与证据

- **2028 是目标入学年份**，不代表报告中的信息都适用于 2028。
- 各项事实保留原报告的适用年度、来源和检索日期。多数资料参考 2026–2027 届；个别项目已记载 2028 年信息。
- “原报告核验日期”沿用上传材料，不会因为网站构建或内容整合而自动更新。
- 本次整合日期为 **2026-10-19**，主要检查内容结构、索引和网站链接，**没有重新逐条联网核验所有招生事实**。
- 当前报告保留 `draft` 草稿状态。网站整合和程序检查不等于人工复核。

## 项目与方向的计数

索引沿用报告中的稳定项目 ID。部分条目是同一招生专业内不同培养方向，因此称为“项目 / 培养方向条目”，不代表同等数量的独立招生学位。共用招生计划不得重复相加。

地区按照原报告归档。例如，香港中文大学（深圳）在中国内地单独建档；纽约大学部分项目在上海培养，须查看项目正文中的校区信息。

方向标签依据项目名称与培养方向生成，仅用于检索。同一项目可以有多个标签；标签不是校方分类、项目评级或申请难度判断。

## 费用与就业比较

不同币种、学年、费用口径、校级或学院级就业统计不能直接排名。对比页面保留原文及来源；遇到“官网未公开”“待核验”或历史参考，须回到官方材料核对。

## 内容与下载

原始报告保存在仓库 `schools/` 中，是维护内容的主文件。网站页面、项目索引和时间线由这些文件生成。PDF 为已提供的配套阅读版；后续修改 Markdown 时，应同步重新导出对应 PDF。网站构建不会自行更改或重排 PDF。

对比选择保存在当前浏览器本地，不需要账号。网站没有提交申请、收集申请材料或保证录取的功能。
